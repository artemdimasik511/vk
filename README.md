# 🎓 Студенческий VK-бот расписания и домашних заданий с Google Gemini AI

Асинхронный бот ВКонтакте для автоматического ведения расписания и домашних заданий студента с помощью нейросети Google Gemini API (`gemini-1.5-flash`) и локальной базы данных SQLite.

---

## 🚀 Возможности

1. **Загрузка расписания по фото (Gemini Vision)**:
   - Отправьте боту фото или скан расписания.
   - Нейросеть распознает дни недели, время пар, дисциплины, аудитории, ФИО преподавателей.
   - Определяет четность недели: `▲` = Нечетная (`ODD`), `■` = Четная (`EVEN`), без знака = Каждую неделю (`ALL`).
   - Определяет тип занятия: `(пр)` / практика = `PRACTICE`, `(л)` / лекция = `LECTURE`.
   - Автоматически обновляет базу данных SQLite и присылает структурированную сводку.

2. **Прием голосовых сообщений с домашним заданием (Gemini Audio)**:
   - Запишите голосовое сообщение (например: *"По матану Иванов задал доказать лемму к следующей паре"*).
   - Бот передает аудио в Gemini вместе с расписанием студента.
   - **Критическое правило**: Задание привязывается **ТОЛЬКО** к практическим занятиям (`lesson_type == "PRACTICE"`), лекции игнорируются!
   - Рассчитывает точную календарную дату ближайшей следующей практики (с завтрашнего дня, до 4 недель вперед), с учетом текущей четности недели относительно точки отсчета **26.10.2026** (нечетная).
   - Очищает текст от мусорных слов и сохраняет в таблицу `homework`.

3. **Удобный интерфейс VK**:
   - Reply-клавиатура:
     - 📅 **Расписание на сегодня**
     - 📆 **Расписание на завтра**
     - 📌 **Мои задания**
     - ℹ️ **Помощь**
   - Команда `/done <ID>` или inline-кнопка для отметки выполненных заданий.
   - Команда `/clear` для сброса расписания.

## 🛠️ Структура проекта

```text
├── main.py            # Точка входа, LongPoll слушатель сообщений VK
├── database.py        # SQLite схема (users, schedule, homework) и CRUD
├── gemini_service.py  # Gemini API (мультимодальное фото и аудио)
├── week_helper.py     # Логика четности / нечетности недель (опорная дата 26.10.2026)
├── keyboards.py       # VK Reply и Inline клавиатуры
├── config.py          # Загрузка токенов и параметров из .env
├── requirements.txt   # Зависимости Python
├── .env.example       # Шаблон переменных окружения
├── .env               # Файл с настроенными ключами
├── run.bat            # Запуск в 1 клик на Windows
└── run.sh             # Запуск в 1 клик на Linux/macOS
```

## ⚡ Быстрый запуск

### Вариант 1: Windows (1 клик)
Просто запустите файл `run.bat`. Он автоматически создаст виртуальное окружение, установит библиотеки и запустит бота.

### Вариант 2: Вручную через терминал

```bash
# 1. Клонируйте или распакуйте проект
cd vk_bot

# 2. Создайте виртуальное окружение Python 3.10+
python -m venv venv

# 3. Активируйте окружение
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# 4. Установите зависимости
pip install -r requirements.txt

# 5. Проверьте .env файл
# Убедитесь, что указаны правильные VK_TOKEN и GEMINI_API_KEY

# 6. Запустите бота
python main.py
```
